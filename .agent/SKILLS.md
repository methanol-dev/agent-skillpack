# Danh Mục Kỹ Năng Hệ Thống (Antigravity Skills Catalog)

> Tổng cộng: **427 Bộ Kỹ Năng** sẵn sàng phục vụ.
> Mỗi thư mục kỹ năng chứa file `SKILL.md` định nghĩa cách kích hoạt và hướng dẫn chi tiết.

---

## 📦 Cách Sử Dụng Kỹ Năng

Khi cần thực hiện tác vụ liên quan đến một kỹ năng, Agent sẽ:
1. Đọc nội dung file `SKILL.md` tương ứng trong `.agent/skills/<tên-kỹ-năng>/SKILL.md`.
2. Áp dụng đúng các chỉ thị, ví dụ và kịch bản thực tế được quy định trong kỹ năng đó.
3. Tuân thủ rào chắn an toàn và tiêu chuẩn chất lượng của dự án.

---

## 📚 Nhóm Kỹ Năng Cốt Lõi Dự Án

- **discord-bot-architect**: Kiến trúc xây dựng Bot Discord chuyên nghiệp (Discord.py, Gateway Intents, Slash Commands, Rate Limiting).
- **ai-agents-architect**: Thiết kế và xây dựng AI Agent tự trị, Function Calling, Model Context Protocol.
- **backend-security-coder**: Lập trình bảo mật backend, chống Injection, SSRF, Path Traversal, Timing Attacks.
- **agent-frontend-patterns**: Mẫu thiết kế giao diện Next.js, React, Tailwind CSS, tối ưu hiệu năng.
- **systematic-debugging**: Quy trình 4 bước điều tra và gỡ lỗi triệt để theo bằng chứng.
- **tdd-master-workflow**: Quy trình phát triển hướng kiểm thử TDD (RED - GREEN - REFACTOR).
- **web_search_service**: Tìm kiếm và bóc tách nội dung Internet thời gian thực.
- **voice-ai-engine-development**: Tích hợp công nghệ âm thanh giọng nói và Edge-TTS.
